# 68yields

**68yields** is a comprehensive platform for yield tracking, analytics, and investment insights. Built with Next.js and Tailwind CSS, it provides powerful tools for investors to monitor and optimize their returns across multiple platforms.

## 🚀 Features

- **Yield Tracking**: Monitor and track yields across multiple investment platforms in real-time
- **Analytics Dashboard**: Visualize performance with charts, trends, and comprehensive analytics
- **Advanced Tools**: Powerful calculation tools and optimization strategies for maximizing returns
- **Responsive Design**: Beautiful, modern UI built with Tailwind CSS
- **Fast Performance**: Powered by Next.js for optimal speed and SEO

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 14.0.3
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) 3.3.6
- **Language**: JavaScript (React 18.2.0)
- **Build Tools**: PostCSS, Autoprefixer

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/alexpie322010/68yields.git
cd 68yields
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
